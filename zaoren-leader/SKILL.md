# zaoren-leader：领导力影响系统

> 管理是把事情做对。领导是做正确的事，并让别人相信这是正确的。
> ——改编自德鲁克与乌尔里克框架

职位权力造的是权力判断树——怎么用职位授权做决策。`zaoren-leader` 造的是影响力系统——ta 怎么在没有强制权力的情况下，让别人主动改变判断。

这是两套完全不同的机制。

---

## 核心区分

| 职位权力（管理者） | 影响力（领导者） |
|---|---|
| 权力来源：职位授权 | 权力来源：信任、专业、愿景 |
| 影响机制：命令与考核 | 影响机制：说服、示范、赋能 |
| 追随原因：不得不 | 追随原因：愿意 |
| 有效范围：下属 | 有效范围：平级、跨部门、甚至上级 |
| 失效条件：离开职位 | 失效条件：失去信任或愿景破裂 |

领导力 ≠ 高职位。一个基层员工可以是真正的领导者，一个 CEO 可以只是在行使权力。

---

## 乌尔里克领导力框架（本 skill 的底层模型）

乌尔里克定义领导者的核心能力是「创造追随者」，分解为五个维度：

**① 塑造未来**：能描述一个让人想去的地方，而且听起来可信
**② 执行当下**：说到做到，建立可预期性，让人敢于追随
**③ 激活个体**：让跟随者感到自己因此变得更好，而不只是在服务领导者的目标
**④ 整合团队**：把不同的人连接成一个有共同目标的系统
**⑤ 建立能力**：为组织的未来投资，而不只是消耗现有资源

## 两种使用模式

### 模式 A：分析一个真实领导者（给我素材，我来造）

给出一个真实人物的素材（言论/行为记录/他人评价），提取其影响力机制。

触发词：「帮我分析为什么他影响力很大」「他是怎么让人跟着走的」「我想学他的方式」

### 模式 B：提升自己的领导力（我是用户，针对我的情境）

用户描述自己的情境，系统帮助诊断当前影响力瓶颈，给出可执行的提升路径。

触发词：「我推不动这件事」「没人支持我」「怎么让别人信任我」「我想提高影响力」

---

## 执行流程

### Step 1：定位影响力现状

先建立影响力基线：

```
[目标：你想影响谁，达成什么]
[当前状态：他们现在的判断是什么]
[你的资源：你有什么可以给他们]
[关系基础：他们为什么会听你说话（或者为什么不）]
```

关键问题：**你的影响力来源是什么？**

- 专业权威：你在这个领域判断比他们准
- 资源控制：你掌握他们需要的东西
- 关系信任：他们相信你不会坑他们
- 愿景感召：你描述的未来让他们想去
- 互惠积累：你之前帮过他们

---

### Step 2：造影响力判断树

格式：

```
[领导者姓名 / 描述]

影响力来源（主要/次要）：
核心资产：ta 拥有什么让别人愿意跟随（专业/资源/信任/愿景/互惠）

影响机制：
  说服路径：ta 通常怎么让别人改变判断
  示范行为：ta 用哪些行动建立可信度
  赋能方式：ta 怎么让追随者变得更好
  边界管理：ta 在哪里不动用权力，为什么

失效条件：
  什么情况下影响力会下降
  什么行为会破坏追随意愿
  ta 的影响力盲区在哪里（不擅长影响哪类人）

可学习的判断规则（L2 以上才能造）：
  情境 X → ta 会用 [影响策略] 而不是 [权力手段]，因为 ……
```

---

### Step 3：影响力瓶颈诊断（模式 B 专用）

如果用户是在提升自己的领导力，做五维诊断：

**维度 1：愿景清晰度**
你有没有一个让人想去的地方？能在 30 秒内说清楚吗？
- 清晰 → 跳过
- 模糊 → 先解决愿景表达问题，再谈影响力

**维度 2：可信度建立**
他们有没有理由相信你能做到你说的？
- 有过去的成功案例 → 调用它
- 没有 → 先做一件小的、可见的、可验证的事

**维度 3：对方动机理解**
你了解他们真正在意什么吗？
- 了解 → 把你的目标和他们的动机对齐
- 不了解 → 先听，再说

**维度 4：互惠积累**
他们感觉跟着你有没有收益？
- 有 → 强化这个感知
- 没有 → 先投入，后影响

**维度 5：示范一致性**
你说的和你做的一致吗？
- 一致 → 继续
- 不一致 → 这是所有影响力问题的根源，先解决这个

---

### Step 4：输出影响力提升方案

```
[情境]：你想在 [时间范围] 内影响 [具体对象] 做 [具体改变]

[当前瓶颈]：最核心的一个障碍是 ……

[可执行路径]：
第一步（本周可做）：……（建立或强化某个影响力来源）
第二步（本月可做）：……（把影响力转化为具体行动支持）
第三步（本季可做）：……（把单次影响变成持续的追随关系）

[不要做的]：
XX 看起来是捷径，但实际上会消耗你的影响力资本，因为 ……

[验证方式]：
3 周后，如果 [具体可观察的行为] 发生了，说明影响力在建立
如果没有，回到 Step 3 重新诊断
```

## 质量标准

| 层级 | 不合格 | 合格 |
|------|--------|------|
| 影响力来源 | 「他很有个人魅力」 | 「他的影响力来自两点：一是他的预测历史上准确率很高，建立了专业权威；二是他在帮别人时从不要求即时回报，建立了信任积累」 |
| 失效条件 | 「如果做错事会失去信任」 | 「他的影响力在两种情况下失效：遇到不在意长期关系的人（一次性博弈），和遇到已经有更强专业权威的人」 |
| 提升建议 | 「要多和别人沟通」 | 「在下次全组会议前，主动找 3 个反对者一对一，只听不说，把他们的顾虑记下来带进讨论——这比在会上争论更有效」 |

**影响力分析如果只停留在「他很厉害」，就没有造出判断系统。**

---

## 反模式声明

### 失败 1：把「他很厉害」当分析，不提取具体影响力来源和机制
用户给了一段某领导者的描述，模型输出「他很有魅力」「他很有远见」这种笼统评价，不提取具体的影响力来源（专业权威？信任积累？资源控制？）和作用机制。
**纠正**：必须回答「他的影响力来自哪类资产」「他用什么具体行为让别人改变判断」。不能停在形容词层面。

### 失败 2：跳过 Step 1 直接给建议，不问「你想影响谁、达成什么」
用户说「我想提升影响力」，模型立刻输出「要多沟通、要展示自信」等通用建议，不先定位影响力现状——影响谁、用什么资源、关系基础是什么。
**纠正**：先完成 Step 1 定位（目标/当前状态/资源/关系基础），再给建议。没有定位的建议是万金油。

### 失败 3：影响力分析只列优点不分析失效条件
模型描述了某领导者「善于沟通」「有远见」「执行力强」，但不分析这个人在什么情况下会失去影响力、影响力盲区在哪里。
**纠正**：每个影响力判断系统必须包含失效条件——什么行为会破坏追随意愿，什么类型的人不会被这种影响力覆盖。

## 与 create 生态的协作

| 场景 | 路径 |
|------|------|
| 分析组织内的真实影响力结构 | `zaoren-roundtable`（多视角碰撞）+ `zaoren-leader`（影响力地图）|
| 推动一个有阻力的变革 | `zaoren-leader`（分析阻力者影响力来源）→ `zaoren-culture`（找阻力背后的文化载体）|
| 造一个具体人物的完整判断系统 | `zaoren`（决策树）+ `zaoren-leader`（影响力层）|
| 培养下一代领导者 | `zaoren-leader` 提取现有领导者的影响力模式 → 传递框架而不是风格 |

## 快速启动

```
模式 A：「帮我分析 [人名/描述] 的领导力」
→ 要求素材（言行记录），进 Step 2 造影响力判断树

模式 B：「我想提升影响力 / 我推不动这件事」
→ 直接进 Step 3 五维诊断，不需要先采集背景
→ 输出 Step 4 方案，必须有「本周可做的第一步」
```

没有可执行的第一步，就不是方案，是建议。
