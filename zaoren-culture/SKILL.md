# zaoren-culture：文化载体分析系统

> 文化不是老板宣布的，是那些真正影响别人行为的人每天示范的。
> ——乌尔里克

`zaoren-leader` 造的是影响力来源。`zaoren-culture` 造的是**文化载体**——那些没有职位、但他们的行为被组织里的人模仿和跟随的人。

变革失败的最常见原因，不是战略错误，不是执行不力，是文化载体没有改变。

---

## 核心概念：文化载体

文化载体（Culture Carrier）是组织里真正定义「这里怎么做事」的人。

他们的特征：
- 不一定是管理者，可能是资深个人贡献者
- 新人会观察他们：「这里的人都是怎么做的？」
- 他们的行为模式被大量复制
- 他们对变革的态度，比管理层的决定更决定变革能不能落地

乌尔里克的研究：组织文化变革中，最关键的不是改变多数人，而是改变核心文化载体的行为。改变了他们，其他人自然跟随。

---

## 两种文化载体类型

### 类型 A：正向载体（变革助力者）
他们体现了组织想要的文化，且被人信任和模仿。
作用：找到他们，让他们显性化，把他们变成变革的示范点。

### 类型 B：负向载体（变革阻力者）
他们体现了组织想要改变的旧文化，且被人信任和模仿。
作用：找到他们，理解他们为什么阻力，不是对抗，是转化——如果能转化，效果比转化 10 个普通人更大。

---

## 文化与价值观的四种关系

| 类型 | 描述 | 诊断信号 |
|------|------|------|
| 一致型 | 宣称的价值观 = 实际行为模式 | 新员工观察一周就能感受到文化 |
| 表演型 | 宣称一套，实际另一套 | 新员工很快学会「说什么」和「做什么」是两回事 |
| 过渡型 | 管理层在推变革，但旧文化还在运转 | 不同部门/团队文化差异很大 |
| 真空型 | 没有主导文化，各团队各自为政 | 「我们没有文化，就是各做各的」 |

诊断方向：找到组织当前处于哪种状态，才能确定文化干预的策略。

## 执行流程

### Step 1：文化诊断

先建立文化现状基线，问三个问题：

**问题 1：新人如何学习「这里的规则」？**
- 通过正式培训 → 表演型风险较高
- 通过观察老员工行为 → 文化载体重要
- 通过犯错被纠正 → 找谁纠正，就找到了文化载体

**问题 2：最近发生过什么「标志性事件」？**
某个行为被奖励或惩罚，让全组织都知道了——这就是文化在运行
- 什么样的行为被奖励（不一定是正式奖励，晋升/好项目/被表扬都算）
- 什么样的行为被惩罚或孤立

**问题 3：谁是组织里「隐形标准的制定者」？**
不是官方规则，是大家心里知道但没写出来的：
- 会议上谁说话算数（不是职位最高的，是「他一说大家就调整」的）
- 谁的工作方式被模仿
- 谁离职后，团队氛围/做事方式发生了明显变化

---

### Step 2：造文化载体判断系统

格式：

```
[文化载体姓名 / 描述]
类型：正向载体 / 负向载体 / 待定

核心行为模式：
  ta 每天重复做的 2-3 件事，让别人感到「这里就是这样做的」

被模仿的原因：
  为什么别人会模仿 ta 而不是其他人
  （专业权威 / 长期信任 / 利益关联 / 情感影响）

文化信号输出：
  ta 在下列情况下如何行动（这些行动被别人观察和学习）：
  - 遇到跨部门摩擦时
  - 遇到资源竞争时
  - 遇到高层决策与自己判断冲突时
  - 遇到新人不懂规则时

变革中的角色判断：
  如果组织推行 [具体变革]，ta 会：
  支持 / 阻力 / 中立观望
  理由（基于 ta 的核心关切和历史行为）：……
  转化策略（如果是负向载体）：……
```

---

### Step 3：文化变革可行性评估

给出一个具体变革，评估文化落地的可行性：

```
[变革目标]：把 [现有文化模式] 变成 [目标文化模式]

正向载体盘点：
  有 X 个正向载体，他们的影响力覆盖 [哪些部门/层级]
  他们对这个变革的态度：支持 / 需要激活

负向载体盘点：
  有 X 个负向载体，他们的影响力覆盖 [哪些部门/层级]
  他们阻力的根本原因：[不是「他们不喜欢变化」，是具体的利益/价值观/习惯]

转化可行性：
  高可行：负向载体的阻力来自信息不足或利益可对齐
  中可行：负向载体的阻力来自习惯或短期利益冲突
  低可行：负向载体的阻力来自根本价值观冲突，且是核心文化载体

关键行动：
  第一步（撬动支点）：找到 1-2 个关键的正向载体，给他们资源和可见度
  第二步（创造标志性事件）：设计一个能被全组织看见的、体现新文化的事件
  第三步（转化或隔离负向载体）：……
  
预计时间：
  文化变革的最小生效周期通常是 6-18 个月
  可以提前观察到的早期信号（3 个月内）：……
```

---

### Step 4：文化健康预警

持续监测文化状态的信号指标：

**绿色信号（文化健康）：**
- 新人能快速融入，且融入后行为模式与目标文化一致
- 标志性事件后，类似行为增加（正向）或减少（负向）
- 文化载体的行为在公开场合被引用和模仿

**黄色信号（需要关注）：**
- 不同团队之间的文化差异越来越大
- 宣称的价值观和实际奖励/惩罚的行为开始出现不一致
- 核心文化载体出现流失信号

**红色信号（需要干预）：**
- 正向载体开始「变现实」（向旧文化妥协）
- 新的负向载体出现且影响力在扩张
- 「说一套做一套」成为大家默认的生存策略

## 质量标准

| 层级 | 不合格 | 合格 |
|------|--------|------|
| 文化载体识别 | 「HR 总监是文化推动者」 | 「真正的文化载体是那个在职 8 年的高级工程师，新人会观察他在代码 review 时的态度，他怎么说，大家怎么认为这里的标准是什么」 |
| 变革可行性 | 「文化变革需要时间和耐心」 | 「当前有 2 个正向载体但都在边缘团队，3 个负向载体在核心产品线——变革可行性中等，需要先把一个正向载体移到核心团队，创造可见性」 |
| 转化策略 | 「要和他多沟通」 | 「他阻力的根本原因是新文化会降低他的专业影响力（他的核心资产是旧系统知识），转化策略：给他一个新文化下的专家角色，让他成为'新旧系统知识的连接者'」 |

**文化分析如果停留在'我们需要更好的文化'，就没有找到载体，没有找到杠杆点。**

---

## 验证方式

做完后问自己几件事。有没有找到具体的文化载体——有名有姓，不是「HR 总监」这种职位标签？有没有给出最小成本的修复方案——不是「加强沟通」这种废话？有没有说清楚变革的最小生效周期和能观察到的早期信号？

## 反模式声明

### 失败 1：把「HR 总监」等同于文化载体
用户说「HR 总监在推文化」，模型就直接把 HR 总监标记为文化载体，不追问「新人向谁学习」。实际上 HR 总监可能只是文化手册的发布者，真正影响行为的是那个没人注意的资深工程师。
**纠正**：文化载体的判断标准只有一个——新人在观察谁的行为来学习「这里怎么做事」。不管头衔，找到被模仿的人。

### 失败 2：停留在「需要更好的文化」，不识别具体载体
用户说「我们公司文化有问题」，模型就输出「需要建立更加开放创新的文化」，不追问「谁在塑造当前的文化」。没有具体载体的文化诊断是空话。
**纠正**：任何文化诊断必须先回答「谁的行为在被组织里被大量复制」，找到载体再谈改变策略。

### 失败 3：把变革阻力归因于「不接受新事物」，不挖掘具体利益
用户说「他们就是不接受新东西」，模型就顺着说「需要加强变革沟通」，不追问「具体是什么利益/习惯/身份在驱动这个阻力」。
**纠正**：阻力分析必须落到具体——是利益受损、习惯打破、还是身份威胁。只有知道阻力来源，才能设计转化策略。

## 与 create 生态的协作

| 场景 | 路径 |
|------|------|
| 推动组织变革 | `zaoren-culture`（识别载体）+ `zaoren-leader`（影响载体）|
| 流程改变落不了地 | `zaoren-process`（找断点）+ `zaoren-culture`（找为什么旧行为模式在维持）|
| 分析一个具体的文化载体 | `zaoren-culture`（识别机制）+ `zaoren`（深度造这个人）|

## 快速启动

```
用户：「我们的变革推不下去」
→ Step 1 文化诊断（找标志性事件 + 找隐形标准制定者）
→ Step 3 变革可行性评估

用户：「帮我分析 [某人] 为什么这么有影响力」
→ 判断是 zaoren-leader（影响力机制）还是 zaoren-culture（文化载体功能）
→ 如果答案是「大家模仿他/她的行为模式」→ 用本 skill

用户：「为什么 [某人] 离职后团队氛围变了」
→ 直接 Step 2 造这个人的文化载体判断系统
→ 识别 ta 承担的文化功能，找到可以替代的正向载体
```

找到关键文化载体，比改变所有人都更有效率。
