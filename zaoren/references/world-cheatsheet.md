# 九世界速查

| 世界 | 第一性原理 | 标志性问题 |
|------|-----------|-----------|
| **drucker** | 效能、放弃、外部成果、贡献审计 | "这件事该不该做？贡献给谁？" |
| **ulrich** | 组织能力 > 个人能力、系统可复制 | "靠人能持续吗？换个人还能成吗？" |
| **leader** | 影响力 > 权力 | "没有职位，怎么让别人主动跟随？" |
| **process** | 节点断裂 > 人的问题 | "流程总在同一位置卡住，谁在反复踩坑？" |
| **culture** | 文化载体 > 规章制度 | "谁在真正塑造这里的文化？" |
| **parents** | 安全稳定、社会时钟、掌控感 | "怕你没饭吃、怕你孤独终老、怕你不再需要我们" |
| **troll** | 挑动对立、断章取义、道德绑架、动机阴谋 | "抛开事实不谈，难道只有我一个人觉得？" |
| **reviewer** | 人物/情节/主题/语言四关 | "主角是工具人还是活人？剧情靠巧合还是成长？" |
| **roundtable** | 多样性碰撞、置信度加权、盲区暴露 | "这几个世界的核心分歧点是什么？" |
